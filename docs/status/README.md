このディレクトリは、**vscode-guitar-dsl** の現在の実装進捗、機能対応状況、および検証状態に関するドキュメントを管理します。

| ドキュメント | 概要 |
|---|---|
| [`implementation-status.md`](implementation-status.md) | 実装進捗ステータス（機能実装マトリクス、テスト自動化検証状況、サンプル整備状況、ロードマップ） |

## ドキュメントの位置づけ

`AGENTS.md` の規定に従い、`docs/status/` は現在の実装および検証状態を把握するためのドキュメントです。
仕様の決定や変更は [`docs/specs/`](../specs/)、内部アーキテクチャ設計は [`docs/design/`](../design/) が正本となります。
