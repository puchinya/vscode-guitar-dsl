# GuitarDSL 言語構文仕様書 (GuitarDSL Syntax Specification)

本書は、ギター弾き語りおよびアコースティックギターストローク譜向けドメイン特化言語 **GuitarDSL** の言語構文、字句規則、およびレンダリング仕様を定義する規範的仕様書（Normative Public Contract）である。

---

## 1. 概要 (Overview)

GuitarDSL は、五線譜・リズムスラッシュ・ピッキング記号（ダウン／アップ）・コードネーム・コードダイアグラム・歌詞から構成されるポピュラー音楽向けリズム譜を、テキストベースで平易に記述するためのDSLである。

- **ファイル拡張子**: `.guitardsl`, `.gdsl`
- **文字エンコーディング**: UTF-8
- **言語種別**: 行指向の宣言的テキストフォーマット

---

## 2. 字句構造 (Lexical Structure)

### 2.1 行指向性
GuitarDSL は行単位で解析される。1行は原則として以下のいずれかの要素を表す。
1. 空行
2. コメント行
3. メタデータヘッダー行
4. セクション見出し行
5. 小節行

### 2.2 空行および空白文字
- 空行（改行のみ、または空白文字のみの行）は無視される。
- トークンを区切る連続した半角空白およびタブ文字は、単一の区切り文字として扱われる。

### 2.3 コメント
- ハッシュ記号 `#` から行末まではコメントとして扱われ、構文解析時に無視される。
- 行頭からのコメントおよび行末コメントの双方が有効である。

```guitardsl
# これは行全体のコメントです
key: C # 行末コメント
```

---

## 3. ドキュメント構成 (Document Structure)

GuitarDSL ドキュメントは通常、以下の順序で構成される。

1. **ヘッダー部**: 楽曲のタイトル、アーティスト、キー、テンポ、カポ位置などのメタデータ
2. **スコア部**: セクション見出しおよび小節行からなる楽譜本体

---

## 4. メタデータヘッダー (Metadata Headers)

メタデータヘッダーは、楽曲全体の属性を定義する。

### 4.1 構文
```text
<key>: <value>
```
- キー名は大文字・小文字を区別しない（Case-insensitive）。
- コロン `:` の前後の空白はトリムされる。

### 4.2 サポートされるヘッダーキー一覧

| キー名 | 別名 | 説明 | デフォルト値 | 描画位置・役割 |
|---|---|---|---|---|
| `title` | - | 楽曲タイトル | `Guitar Rhythm Score` | ヘッダー最上部に大見出しで表示 |
| `artist` | - | アーティスト名／作詞・作曲者 | (空) | タイトル直下に `Words & Music: <artist>` として表示 |
| `capo` | - | カポタストの位置（フレット数） | `0` | 右上部に `Capo: <capo>` バッジとして表示 |
| `key` | `original_key` | 楽曲のキー（調） | `C` | 右上部に `Key: <key>` として表示 |
| `bpm` | `tempo` | テンポ（拍/分） | `90` | 右上部に `BPM: <bpm>` として表示 |
| `memo` | - | 演奏上の注意・メモ | (空) | ドキュメント内のメタ情報（将来拡張用） |

### 4.3 記述例
```guitardsl
title: 風のコンパス - Wind Compass
artist: GuitarDSL Original
capo: 0
key: C
bpm: 104
memo: 軽快な8ビートストローク。
```

---

## 5. セクション見出し (Section Headers)

楽曲の構造（Intro、Aメロ、サビなど）を示す見出しラベルを定義する。

### 5.1 構文
```text
[<セクション名>]
```
- 行頭が `[` で始まり、行末が `]` で終わる行がセクション見出しとして認識される。
- セクション名には英数字、記号、日本語（ひらがな・カタカナ・漢字等）を含む任意の文字列が使用可能。

### 5.2 振る舞い
- セクション見出しが定義されると、その直後に出現する**先頭の小節の上部**に、四角い枠線で囲まれたセクションボックスとして描画される。
- 1つのセクション指定は1回のみ消費され、後続の小節には引き継がれない。

### 5.3 記述例
```guitardsl
[Intro]
| C | 4.d 4.d 4.d 4.d |

[サビ]
| F | 8.d 8.u 4.d 8.d 8.u 4.d |
```

---

## 6. 小節行と小節線 (Measures and Barlines)

楽譜の小節および小節線（小節区切り）を定義する。行内にパイプ記号 `|` が含まれる場合、小節行として解析される。

### 6.1 小節線記号 (Barlines)

| 記号 | 名称 | 説明・描画 |
|---|---|---|
| `\|` | 通常小節線 | 1本の細い縦線で小節を区切る。 |
| `\|:` | リピート開始線 | 左側に太線、右側に細線、および2つのリピートドットを描画。 |
| `:\|` | リピート終了線 | 左側に2つのリピートドット、細線、右側に太線を描画。 |

### 6.2 小節の記述形式

小節は以下のいずれかの形式で記述できる。

#### 形式A: 1小節内にコードとリズムを併記
```guitardsl
| C 4.d 4.d 4.d 4.d | G 4.d 4.d 4.d 4.d |
```

#### 形式B: コードセルとリズムセルを分割（推奨可読形式）
```guitardsl
| C  | 4.d 4.d 4.d 4.d |
| G  | 4.d 4.d 4.d 4.d |
```
- パーサーは、「コードのみを含むセル」の直後に「リズムのみを含むセル」が存在する場合、それらを単一の小節データとして自動結合（マージ）する。

#### 形式C: リピート記号を含む小節
```guitardsl
|: C | 4.d 4.d 4.d 4.d |
|  F | 4.d 4.d 4.d 4.d :|
```

## 7. コード表記 (Chords)

各小節で演奏するギターの和音（コードネーム）を指定する。

### 7.1 構文規則
コードトークンは以下の正規表現パターンに合致する文字列である。

```regex
^[A-G][b#]?(maj|m|min|aug|dim|sus[24]|add9|[0-9]+)*(\/[A-G][b#]?)?$
```

- **ルート音**: `A` 〜 `G`（必要に応じて半音下げ `b` または半音上げ `#`）
- **コードクオリティ / テンション**:
  - メジャー / マイナー: `m`, `min`, `maj`
  - サスペンデッド: `sus2`, `sus4`
  - オーグメント / ディミニッシュ: `aug`, `dim`
  - セブンス / ナインス / テンション: `7`, `maj7`, `m7`, `add9` 等
- **オンコード（分数コード）**: スラッシュ記号 `/` に続けてベース音を指定（例: `G/B`, `D/F#`）

### 7.2 コードダイアグラム (Chord Diagrams)
スコア内で一度でも使用されたコードは自動的に収集され、楽譜上部のダイアグラム領域にフレット指板図として一覧描画される。

- 組み込みコードライブラリ（`CHORD_LIBRARY`）に登録されているコード:
  - 基本コード: `C`, `G`, `D`, `A`, `E`, `F`
  - マイナーコード: `Am`, `Em`, `Dm`
  - セブンスコード: `B7`, `Dm7`, `Am7`, `Em7`, `G7`, `C7`, `A7`, `E7`, `Bm7`, `Fmaj7`
  - テンション・分数コード: `Cadd9`, `G/B`, `D/F#`
- ライブラリ未登録コード: デフォルトのコードダイアグラム形状にフォールバックされる。

## 8. リズム・ストローク記法 (Rhythm and Stroke Tokens)

各小節内のストロークパターン、ピッキング方向、アクセント、音価を定義する。

### 8.1 トークン書式
```text
<音価>[.<修飾子1>.<修飾子2>...]
```
ドット `.` で区切ることで、音価に対して複数の修飾子（ピッキング方向、表現など）を付与する。

### 8.2 音価 (Duration)

| 指定値 | 名称 | 楽譜上での意味・描画表現 |
|---|---|---|
| `1` または `w` | 全音符 (Whole note) | 4拍分の長さ。幅広の白抜きスラッシュヘッド（符幹なし）として小節中央に描画 |
| `2` または `h` | 2分音符 (Half note) | 2拍分の長さ。白抜きのスラッシュヘッド＋符幹として描画 |
| `4` または `q` | 4分音符 (Quarter note) | 1拍分の長さ。黒塗りのスラッシュヘッド＋符幹として描画 |
| `8` | 8分音符 (Eighth note) | 1/2拍分の長さ。黒塗りスラッシュヘッド＋符幹。同拍内の音符とは太い連桁（ビーム）で結線（孤立時は旗） |
| `16` | 16分音符 (Sixteenth note) | 1/4拍分の長さ。黒塗りスラッシュヘッド＋符幹。同拍内の音符とは二重連桁（ビーム）で結線（孤立時は二重旗） |

### 8.3 休符 (Rest)
- 音価の先頭に `r` を付与することで休符となる（例: `r1`, `rw`, `r2`, `rh`, `r4`, `rq`, `r8`, `r16`）。
- 楽譜上には音価別のベクター休符記号（全休符: 第4線吊り下げ、2分休符: 第3線上、4分休符、8分休符、16分休符）として描画され、スラッシュヘッドやピッキング記号は描画されない。

### 8.4 修飾子 (Modifiers)

| 修飾子 | 完全名 | 名称 | 描画・効果 |
|---|---|---|---|
| `d` | - | ダウンストローク | スラッシュ上部にダウンピッキング記号（`п`）を描画 |
| `u` | - | アップストローク | スラッシュ上部にアップピッキング記号（`∨`）を描画 |
| `g` | `ghost` | ゴーストノート | ブラッシング／ミュートストローク。透明度35%で薄く描画 |
| `a` | `accent` | アクセント | スラッシュ上部にアクセント記号（`>`）を描画 |
| `t` | `tie` | タイ | 音を伸ばすタイ属性（後続音との連結情報） |

### 8.5 記述例
- `4.d`: 4分音符のダウンストローク
- `8.u`: 8分音符のアップストローク
- `16.d.a`: 16分音符のダウンストローク（アクセント付き）
- `8.d.g` または `8.d.ghost`: 8分音符のダウングーストノート（ブラッシング）
- `1.d`: 1小節伸ばす全音符ダウンストローク

### 8.6 リズム省略時のデフォルト補完
小節内にリズムトークンが1つも指定されていない場合、パーサーは自動的に以下のデフォルトリズム（4分音符4拍）を補完する。
- 1拍目: `4.d`（4分音符ダウンストローク）
- 2拍目: `4`（4分音符ストローク方向なし）
- 3拍目: `4.d`（4分音符ダウンストローク）
- 4拍目: `4`（4分音符ストローク方向なし）

## 9. 歌詞記法 (Lyrics)

小節内の該当位置に対応する歌詞テキストを指定する。

### 9.1 構文
```text
l:"<歌詞テキスト>"
```
または
```text
~"<歌詞テキスト>"
```
- ダブルクォート `"` で囲まれた文字列が歌詞として抽出される。
- 小節内の任意の位置（通常は小節末尾）に記述可能。

### 9.2 描画
- 当該小節の五線譜最下線の真下（中央揃え）に歌詞テキストとしてレンダリングされる。

### 9.3 記述例
```guitardsl
| C | 8.d 16.d 16.u 8.d 8.u 4.d l:"あさのひかりを あびながら" |
```

## 10. レンダリング・レイアウト仕様 (Rendering and Layout Rules)

GuitarDSL コンパイラが生成する SVG / HTML 楽譜の表示規則は以下の通りである。

1. **システム（段）構成**:
   - 楽譜は**1段あたり4小節**で自動的に折り返される。
   - 各段の全幅は 780px、各小節は均等に割り振られる。
2. **段頭の記号**:
   - すべての段の先頭に五線とト音記号（Treble Clef）が描画される。
   - 第1段のト音記号直後にのみ、4/4 拍子記号が表示される。
3. **垂直レイアウト順（上から下）**:
   1. セクション名（`[Intro]` 等の枠付きラベル: y=6〜22）
   2. コードネーム（太字テキスト: baseline y=32）
   3. アクセント記号（`>`: y=38〜44）
   4. ピッキング記号（`п`, `∨`: y=47〜52）
   5. 連桁・符幹（Beams / Stems: y=60〜79）
   6. 五線譜（Stave Lines: 5本線 y=70, 78, 86, 94, 102）およびリズムスラッシュヘッド（第3線 y=86 を中心に配置、全音符・2分音符は白抜き、4分音符以下は黒塗り）
   7. 歌詞テキスト（五線下部 y=120）
4. **印刷・ページ設定**:
   - A4縦（Portrait）サイズに最適化されたスタイルシートが適用される。
   - 上部に「A4印刷 / PDF保存」ボタンが提供され、ブラウザ印刷ダイアログから直接PDF出力が可能（印刷時にはボタンは非表示）。

## 11. 完全なサンプルコード

```guitardsl
title: 風のコンパス - Wind Compass (Acoustic Rhythm Score)
artist: GuitarDSL Original
capo: 0
key: C
bpm: 104
memo: 軽快な8ビートストローク。サビはシンコペーションとアクセントを意識して演奏。

[Intro]
|: C  | 4.d 4.d 4.d 4.d |
|  G  | 4.d 4.d 4.d 4.d |
|  Am | 4.d 4.d 4.d 4.d |
|  F  | 4.d 4.d 4.d 4.d :|

[Aメロ]
| C   | 8.d 16.d 16.u 8.d 8.u 4.d l:"あさのひかりを あびながら" |
| G   | 8.d 16.d 16.u 8.d 8.u 4.d l:"あたらしいドアを ひらく" |
| Am  | 8.d 16.d 16.u 8.d 8.u 4.d l:"ちいさなコンパス てににぎり" |
| Em  | 8.d 16.d 16.u 8.d 8.u 4.d l:"まだみぬまちへ あるきだす" |

[サビ]
| C   | 8.d 8.u 4.d 8.d 8.u 4.d l:"めざしたあのばしょへ" |
| G   | 8.d 8.u 4.d 8.d 8.u 4.d l:"ひかりをつないでゆく" |
| Am  | 8.d 8.u 4.d 8.d 8.u 4.d l:"なみだも えがおにかわる" |
| F   | 8.d 8.u 4.d 8.d 8.u 4.d l:"ぼくらのものがたり" |

[Outro]
| C   | 4.d 4.d 4.d 4.d l:"ここからはじまる" |
| G   | 4.d 4.d 4.d 4.d |
| F   | 4.d 4.d 4.d 4.d |
| C   | 1.d :|
```
