## ドキュメントの位置づけ

`AGENTS.md` の規定に従い、`docs/design/` は拡張機能の内部構造および実装モデルに関する設計仕様です。
外部振る舞いや言語仕様については [`docs/specs/`](../specs/)、現在の実装進捗状況については [`docs/status/`](../status/) を参照してください。
