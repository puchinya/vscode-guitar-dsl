オープンソースのギター譜エディター

テキストから、
ギターの楽譜を作成。

GuitarDSLは、オープンソースソフトウェア（OSS）です。 市販の弾き語り楽譜でよく見るコード・ストローク・歌詞付きの譜面や、歌唱メロディを載せた弾き語り譜、ソロギターのTAB譜をテキストで作成できます。専用のテキスト記法（DSL）を編集しながら、譜面のプレビューを同じ画面で確認できます。

このページは公開前のデザイン資料です。実際の遷移と譜面画像は実装・検証後に差し替えます。

用途別の楽譜

3つの楽譜の作成例

オリジナル曲「空色の合図」を使い、歌唱メロディのない弾き語り譜、歌唱メロディ付きの弾き語り譜、ソロギターのTAB譜を紹介します。各例にはGuitarDSLの記述例と、対応する譜面の表示例を掲載します。曲・歌詞・旋律は紹介用に作成したもので、既存のアニメ作品や楽曲とは関係ありません。

作成例 01 / コード・ストローク・歌詞

弾き語り楽譜（メロディなし）

市販の弾き語り楽譜でよく使われる、コード名・ストローク・歌詞をまとめた譜面を作成できます。歌唱メロディの音符は載せず、ギター伴奏と歌詞を確認したい場合に向いています。

空色の合図.guitardslGuitarDSL
title: 空色の合図
artist: GuitarDSL Original Demo
key: C
bpm: 104
time: 4/4
measures_per_row: 4

[Verse]
| C G   | 4.d 8.d 8.u 4.d 8.d 8.u l:"あさのそらに" |
| Am Em | % l:"ひかりがさす" |
| F C   | 4.d 8.d 8.u 4.d 8.d 8.u l:"まだみぬみち" |
| Dm G7 | % l:"かぜをこえて" |
  • コードとリズムを別セルで記述
  • 直前小節のストロークは % で再利用
  • 小節単位の歌詞を l: で追加
作成例 02 / メロディ・歌詞・伴奏

弾き語り楽譜（メロディあり）

コードとストロークに加えて、歌うメロディの音符と歌詞を記述できます。音の高さや長さを五線譜で確認しながら、同じ曲のギター伴奏も扱えます。

空色の合図.guitardslGuitarDSL
title: 空色の合図
artist: GuitarDSL Original Demo
key: C
bpm: 104
time: 4/4
measures_per_row: 4

[Verse]
| C G   | 4.d 8.d 8.u 4.d 8.d 8.u |
| Am Em | % |
| F C   | 4.d 8.d 8.u 4.d 8.d 8.u |
| Dm G7 | % |

mel: | e4/8 g g/4 d/8 b3 g/4 | a4/8 c5 e/4 b4/8 g e/4 |
lyr: | あ さ の そ ら に | ひ か り が さ す |
mel: | f4/8 a c5/4 g4/8 e c/4 | d4/8 f a/4 b/8 d5 g/4 |
lyr: | ま だ み ぬ み ち | か ぜ を こ え て |
  • 歌唱メロディを mel: で記述
  • 各音符に対応する歌詞を lyr: に記述
  • メロディなし版と同じコード進行を利用
作成例 03 / ソロギター・TAB譜

ソロギターのTAB譜

低音の伴奏と高音のメロディを1本のギターで弾く、フィンガースタイルの譜面例です。弦・フレット・音価を記述し、[5f3,2f1] のように同時に鳴らす弦も指定できます。

空色の合図.guitardslGuitarDSL
title: 空色の合図 — ソロギター
artist: GuitarDSL Original Demo
key: C
bpm: 104
time: 4/4
measures_per_row: 4

[Verse]
| C G   |
| Am Em |
| F C   |
| Dm G7 |

tab: | [5f3,2f1]/8 3f0 1f0 2f1 [6f3,2f0] 3f0 1f3 2f0 |
tab: | [5f0,2f1]/8 3f2 1f0 2f1 [6f0,2f0] 3f0 1f0 2f0 |
tab: | [6f1,2f1]/8 3f2 1f1 2f1 [5f3,2f1] 3f0 1f0 2f1 |
tab: | [4f0,2f3]/8 3f2 1f1 2f3 [6f3,2f0] 3f0 1f1 2f0 |
  • 低音と高音を交互に弾くフィンガースタイル
  • [5f3,2f1] でベース音と旋律を同時に発音
  • 直前と同じ音価は省略できる
編集・プレビュー・保存

書いた内容を譜面で確認

DSLを編集しながら譜面をプレビューし、必要に応じてPDFに書き出せます。楽譜と下書きはブラウザー内に保存できます。Google Driveは任意で接続でき、Explorerからファイルを管理できます。

GuitarDSLを使う

ブラウザーでWebエディターを開き、楽譜を作成できます。操作方法はアプリ内のヘルプから確認できます。

設計参照用HTMLのため遷移は未実装です。公開版では本番 www.guitardsl.app → guitardsl.app、開発 wwwdev.guitardsl.app → dev.guitardsl.app に遷移します。
