GUITAR SCORE EDITOR · OPEN SOURCE

テキストで書く、
ギターのための楽譜。

GuitarDSLは、コード進行、ストローク、TAB、メロディ、歌詞をテキストで記述し、譜面として確認できるオープンソースのエディターです。弾き語り用のコード譜からメロディ付きの楽譜まで、ソースの編集と譜面の確認を同じ画面で行えます。

個人開発のOSSプロジェクトとして公開・開発しています。 機能を見る

このHTMLはデザイン参照用です。開始操作のアプリ連携はCodexの実装対象です。

FEATURES

GuitarDSLで扱える楽譜と情報

コード進行やリズムを記述するほか、TAB、メロディ、歌詞にも対応しています。下記はWeb版で扱う主な要素です。

コードとストローク

コード進行とストロークを別セルで記述し、繰り返し記号も使用できます。

メロディ・TAB・歌詞

小節単位の歌詞に加え、音符と歌詞の対応やTAB譜も記述できます。

編集とプレビュー

ソースを編集しながら譜面を確認できます。記述に問題があればProblemsパネルで確認します。

WORKSPACE

ソースと譜面を並べて確認

Explorerで楽譜を管理し、中央ではソースとプレビューを表示します。Inspectorとチュートリアルは右側のパネルで切り替えます。

  • ソース／分割／譜面表示の切り替え
  • コード譜の編集、プレビュー、PDF出力
  • 右サイドパネルの切り替え
SCORE AS CODE

コードとストロークの記述例

コードを左セル、ストロークを右セルに記述します。直前小節のストロークを繰り返す場合は % を使います。

歌詞は小節ごとに追加できます。メロディ付き楽譜では音符に対応した歌詞も記述できます。

右はDSLテキストの例であり、GuitarDSLがレンダリングした譜面画像ではありません。

momiji.guitardsl — 文法例（簡易伴奏）
title: 紅葉（もみじ）
key: C
time: 4/4

[Verse 1]
| C G7 | 4.d 8.d 8.u 4.d 8.d 8.u l:"秋の" |
| C G7 | % l:"夕日に" |
| C G7 | 4.d 8.d 8.u 4.d 8.d 8.u l:"照る山" |
| C G7 | % l:"紅葉" |
MELODY, TAB, LYRICS

歌詞・メロディ・TABの扱い

歌詞付きのコード譜を作り、必要に応じて音符を伴うメロディやTABを記述できます。原曲のメロディーとその歌詞を使う場合は、音高・音価・音節の対応を確認します。

「紅葉」メロディ版は原譜照合と試奏の受入条件が残るため、未確認の画像を実画面として載せません。

メロディ譜・歌詞表示 Codexが検証済みのmel:/lyr:楽譜を実際に表示し、撮影後に画像を配置する箇所です。
TAB譜の実画面 既存の有効なTAB fixtureを用いてレンダリングし、Codexが撮影後に置き換えます。
TUTORIAL

編集しながら使い方を確認

チュートリアルは右サイドパネルに表示します。教材「紅葉」を使って、メロディなしの歌詞付きコード譜と、メロディ付き楽譜を段階的に作成する構成です。

チュートリアルの完了判定・教材の音楽的検証はPR #190の確認対象です。公開までに確認済み状態へ更新する必要があります。

STORAGE

保存先について

楽譜と下書きは、この端末のブラウザー内に保存できます。必要に応じてGoogle Driveに接続し、Explorerから楽譜を管理できます。

  • GoogleアカウントなしでもWebエディターを使用できます。
  • Google Driveへの接続は任意です。
  • 保存先と接続状態はエディターから確認できます。

GuitarDSLを開く

開始するとWebエディターに移ります。使い方はヘルプとチュートリアルから確認できます。

このファイルは設計参照用です。アプリ内の画面切り替え、初回完了の保存、ヘルプからの再表示はCodexが実装します。
