## GuitarDSL 言語
<!-- help-sources: syntax:2 syntax:3 -->

GuitarDSL は行単位で書きます。空行は無視され、`#` 以降はコメントです（行全体でも行末でも使えます）。ドキュメントは通常、**ヘッダー**（曲の情報）と、それに続く**楽譜**（セクション見出しと小節行）で構成します。

### ヘッダー
<!-- help-sources: syntax:4 -->

ヘッダーは `キー: 値` の形式で書きます。キーの大文字・小文字は区別しません。

```guitardsl
title: 風のコンパス
artist: GuitarDSL Original
capo: 2
key: D
bpm: 104
time: 4/4
```

| ヘッダー | 意味 |
|---|---|
| `title`、`artist` | 1 ページ目の上部に表示 |
| `capo` | カポの位置（カポ関連の機能は 0〜12 を扱う）。コード名は**押さえる形**を表します |
| `key`（`original_key`） | **実際に鳴る**調。メロディの調号にも使います |
| `bpm`（`tempo`） | ヘッダーに表示するテンポ |
| `time`、`feel`、`pickup` | 冒頭の拍子、フィール（`straight` / `swing` / `shuffle`）、弱起の長さ |
| `measures_per_row` | 1 段あたりの小節数（1〜8、既定 4） |
| `show_rhythm` | `false` にすると、メロディのある段でリズム譜表を省略（リードシート） |
| `chord_size`、`lyric_size`、`title_size`、`section_size`、`font_size` | 文字サイズ |

### セクション編曲と出現ごとの歌詞
<!-- help-sources: syntax:3 syntax:5 syntax:8 syntax:13 -->

`arrangement { ... }` をヘッダーの後、スコア本文の前に置くと、既存のセクション見出しを並べて演奏順を指定できます。小節を複製して書く必要はありません。

```guitardsl
arrangement {
  Intro
  Verse
  Chorus x2
  Verse(lyr=2)
}

[Intro]
| C |
[Verse]
| Am | F |
mel: | a4/1 | g4/1 |
lyr: 朝 光
lyr: 雨 夜
[Chorus]
| G |
```

名前は見出しと大文字小文字・空白も含めて一致させます。空白を含む見出しは `[Verse A]` のように括弧付きで参照します。`x2` はそのセクションを2回演奏します。歌詞番を省略すると、同名セクションの出現ごとに次の番を選びます。`Verse(lyr=2)` はその出現だけ2番を選び、書面の `lyr:` 行と楽譜表示は変えません。編曲ブロックがある文書では、明示反復・volta・D.C./D.S. などのナビゲーション記号と併用できません。

### セクション・小節・小節線
<!-- help-sources: syntax:5 syntax:6 syntax:8 -->

`[Intro]` や `[サビ]` のような行は、次の小節の上にセクション名を表示します。`|` を含む行が小節行です。コードとリズムは 1 つのセルにまとめても、コードのセルとリズムのセルに分けても書けます。行を次の行に続ける書き方はありません。

```guitardsl
[Intro]
| C 4.d 4.d 4.d 4.d | G 4.d 4.d 4.d 4.d |
| Am | 4.d 4.d 4.d 4.d |
```

小節線と演奏順序の記号は次のとおりです。

- `|` 通常の小節線、`|:` と `:|` 反復、`||` 複縦線、`|]` 終止線。対応する未終了の `|:` がない `:|` は、直前のセクション見出しまたは楽譜の先頭を起点にする暗黙の反復として扱います。記法の警告は演奏順とは別に判定されます。
- `[1.]`、`[2.]` などの volta は演奏回を指定します。番号のリストや範囲も書けます（例: `[1,3-4.]`）。カッコは終了セグメントの最初の小節に記述し、後続のカッコのない小節も `:|` まで同じ終了に含まれます。該当しない演奏回ではセグメント全体を飛ばします。終了 `:|` の直後に次の volta が続く場合は同じ反復を共有します。終了後、次の volta までにカッコのない小節があると共有は終わります。改ページだけでは共有は終わりません。
- 改ページは表示だけの区切りで、演奏順の解決や volta の共有を変えません。`repeatEndWithoutStart` 警告は別に判定され、抑制するかどうかはページ境界も考慮します。
- `Segno`、`Coda`、`to Coda`、`D.S.`、`D.C.`、`Fine` は演奏順の移動や終了を指定します。`D.C.` / `D.S.` は楽譜全体で 1 つまでで、使用するジャンプ先は一意である必要があります。
- `%` 前の小節の繰り返し。コードを省略すると前の小節のコードを引き継ぎます

これらの記号から書かれた小節の演奏順を解決します。演奏順は小節の表示順を変えず、GuitarDSL は音声再生を行いません。

### コード
<!-- help-sources: syntax:7 -->

コード名は「ルート + 種類 + 任意のベース音」です（例: `C`、`Am7`、`Fmaj7`、`Gsus4`、`Cadd9`、`D/F#`）。

- コードのセルに複数のコードを並べると、小節を均等に分けます: `| C G | ... |`
- 長さは `:` で拍数、`/` で音価として指定します: `C:3 G:1`、`C/2+8 G/4.`、`G/B/2`
- リズムの間に書いたコードは、その位置で切り替わります: `| C 4.d 4.d G 4.d 4.d |`

#### コード定義
<!-- help-sources: syntax:7 -->

`chord` 行でダイアグラムの押さえ方を定義します。フレットは 6 弦から 1 弦の順に書きます（`x` = ミュート、`0` = 開放、数字 = フレット）。`@ラベル` を付けると、同じコードの複数の押さえ方を定義できます。

```guitardsl
chord C       = x32010
chord C@barre = x35553 fingers:-13331 barre:3
chord C@high  = x,x,10,9,8,8 fingers:--4312

[Intro]
| C@barre:2 C@high:2 | 4.d 4.d 4.d 4.d |
```

オプションは次のとおりです。

- `base:<フレット>`: 開始フレット
- `fingers:<6文字>`: 指番号（`-`、`1`〜`4`、`T`）
- `barre:<フレット>` または `barre:<フレット>:<弦>-<弦>`: セーハ

### リズムとストローク
<!-- help-sources: syntax:8 -->

リズムトークンは「音価 + `.` で区切った修飾子」で書きます。

| トークン | 意味 |
|---|---|
| `1` `2` `4` `8` `16`（`w` `h` `q` も可） | 全音符・2 分・4 分・8 分・16 分 |
| `8t` `4t` `16t` | 3 連符 |
| `8{5:4}` | 一般の連符（4 つ分の長さに 5 つ） |
| `4+8` | 長さの加算（タイで描画。付点はこれで書く） |
| `r4`、`r8` など | 休符 |

修飾子は次のとおりです。例えば `16.d.a` は、アクセント付きの 16 分のダウンストロークです。

- ストローク: `d` ダウン、`u` アップ
- 表情: `a` アクセント、`g` ゴースト、`t` タイ、`arp` アルペジオ
- 奏法: `pm` パームミュート、`lr` レットリング、`stacc`、`ten`、`fermata`、`vib`、`breath`

```guitardsl
| C | 8.d 16.d 16.u 8.d 8.u 4.d.a r4 |
| G | 8t.d 8t.u 8t.d 4.d 4+8.d 8.u |
```

リズムを書かない小節には既定のパターンが入ります。小節の拍数の合計が拍子と合わないと警告になります。

### 歌詞
<!-- help-sources: syntax:9 -->

小節の中に `l:"..."`（または `~"..."`）を書くと、その小節の下に歌詞を表示します。

```guitardsl
| C | 8.d 8.u 4.d 8.d 8.u 4.d l:"あさのひかりを あびながら" |
```

### 改ページ
<!-- help-sources: syntax:10 -->

`---` または `pagebreak` だけの行で改ページします。

### メロディと音符単位の歌詞
<!-- help-sources: syntax:12 syntax:13 -->

`mel:` 行は、その上にある小節のメロディを 1 セル 1 小節で書きます。

- 音符は「小文字の音名 + 任意の `#` / `b` + オクターブ + 長さ」で書きます（例: `e4/8`、`f#4/4`、`bb3/2`、`a4/4.`、休符 `r/8`、タイ `g4/2~`）。
- 同じ行の中では、オクターブと長さは前の音符から引き継がれます。

`mel:` の後の `lyr:` 行は、歌う音符に 1 音節ずつ割り当てます。

- 日本語は 1 文字 1 音節です（`ゃ` などの小書き文字は前の文字と 1 音節）。
- `_` は前の音節を伸ばし、`*` は音符を 1 つ飛ばします。
- 番を増やすときは `lyr:` 行を追加します。

```guitardsl
key: C
| C  | 8.d 8.u 4.d 8.d 8.u 4.d |
| G  | % |
mel: | r/8 e4/8 e g a g e d | d4/8 d e d c/4 r/4 |
lyr: | あさのひかりを | あびながら |
```

奏法は、長さの後に波括弧で書きます: `{hammer}`、`{pull}`、`{slide}`、`{gliss}`、`{bend:1}`、`{vibrato}`、`{staccato}`、`{tenuto}`、`{fermata}`、`{breath}`、`{grace}`、`{slur-start}`、`{slur-end}`、`{pm}`、`{let-ring}`。

### 調号と表示設定
<!-- help-sources: syntax:14 -->

`key:` ヘッダーからメロディの調号を決めます（例: `C`、`G`、`Bb`、`F#m`）。メロディは常に実際の音高で書きます。`show_rhythm: false` にすると、メロディのある小節ではメロディ譜表だけを表示します。

### スコアイベント
<!-- help-sources: syntax:16 -->

`@` で始まる行は、**次の小節**から設定を変えるか、次の小節に記号を付けます。

```guitardsl
key: C
bpm: 120
| C | G |
@key: D
@tempo: 132
@dynamic: f
| D | A |
@time: 7/8(2+2+3)
@mark: B
| Em | 8.d 8.u 8.d 8.u 8.d 8.u 8.d |
```

使えるイベントは次のとおりです。

- `@key:`
- `@tempo:`（数値、`rit.`、`accel.`、`a tempo`、`tempo primo`）
- `@time:`
- `@feel:`
- `@dynamic:`
- `@mark:`
- `@text:`
- `@ottava:`（`8va`、`8vb`、`off`）

数値の `@tempo:` はその小節からプレビュー再生のテンポを変え、`tempo primo` はヘッダーの `bpm:` に戻します。`rit.`、`accel.`、`a tempo` と `feel` は表示のみで、再生タイミングは変わりません。強弱とオッターヴァは記譜だけに影響します。

### 再利用フラグメント（`let`）
<!-- help-sources: syntax:17 -->

`let` でリズムや音符の並びに名前を付け、小節や `mel:` のセルの中で `$名前` として再利用できます。定義はファイルのどこに書いても構いません。

```guitardsl
let groove = 8.d 8.u 4.d 8.d 8.u 4.d
let riff = e4/8 g a g
[Aメロ]
| C | $groove |
| G | $groove |
mel: | $riff $riff | c5/2 r/2 |
```

- 定義の最初の音符は、オクターブと長さを省略せずに書きます（`let riff = e4/8 g`）。
- 参照は、前後の音符とオクターブ・長さを受け渡ししません。
- 定義の中では `%` を使えません。定義同士の循環参照もできません。

### 同時複数音（Note Groups）
<!-- help-sources: syntax:18 -->

同時に鳴る音は、角括弧で囲んで 1 つの長さを共有させます: `[c4,e4,g4]/4`。

- 各構成音にはオクターブが必要です。
- `{staccato}` などの奏法は付けられます。
- タイ・ハンマリング・スライド・チョーキング・スラーは付けられません。

```guitardsl
| C | [c4,e4,g4]/4 [c4,eb4,g4]/8 8.u 4.d [c4,e4,g4]/4{staccato} |
| C | G |
mel: | [c4,e4,g4]/2 [d4,f4,a4]/2 | [c4,e4,g4]/4. [d4,f4]/8 [e4,g4]/2 |
```

### 描画とレイアウト
<!-- help-sources: syntax:11 -->

- 各段の先頭にはト音記号、第 1 段には拍子記号を描画します。
- コード名は五線の上、ストローク記号はスラッシュの上、歌詞は下に描画します。
- 調や拍子が変わる小節からは新しい段になります。

規則の詳細は GuitarDSL 構文仕様書（ソースリポジトリの `docs/specs/guitardsl-syntax.md`）にあります。
