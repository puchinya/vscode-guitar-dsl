## トラブルシューティング
<!-- help-sources: extension:5A -->

### 波線と「問題」パネル
<!-- help-sources: extension:5A syntax:7 syntax:8 syntax:12 syntax:13 syntax:17 syntax:18 -->

GuitarDSL は入力中にファイルを検査します。

- **エラー**: その行・トークンは無視されます（例: 未知のスコアイベント、不正なコード定義）。
- **警告**: 楽譜は描画されますが、意図どおりでない可能性があります（例: 拍数が合わない小節）。

波線にマウスを置くか、**問題** パネルでメッセージを確認してください。よくある原因は次のとおりです。

| メッセージの内容 | 確認すること |
|---|---|
| 小節の長さ | 小節内のリズム・音符の合計を拍子に合わせます（4/4 なら 4 拍）。リズムトークンの付点は `4.` ではなく `4+8` と書きます。 |
| 音名が大文字 | メロディの音名は小文字です（`e4/8`）。大文字はコード名として扱われます。 |
| `mel:` の最初の音符 | 各 `mel:` 行と各 `let` 定義の最初の音符には、オクターブと長さが必要です（`e4/8`）。 |
| `mel:` のセルが多すぎる | 同じセクション内で、メロディのない小節よりメロディのセルが多くなっています。 |
| 音節の数 | `lyr:` の音節数と歌う音符の数が合っていません。`_` で伸ばし、`*` で音符を飛ばせます。 |
| `l:"..."` とメロディの併記 | メロディのある小節は `lyr:` を使います。その小節の `l:"..."` は表示されません。 |
| コード定義 | フレットを 6 弦から 1 弦の順に 6 つ書き、押弦位置は開始フレットから 5 フレット以内に収めます。 |
| 定義のない `@ラベル` | `C@x` を使っているのに `chord C@x = ...` がありません。ラベルなしの `C` の押さえ方で描画されます。 |
| `let` / `$名前` | 未定義の名前、循環参照、定義の中の `%`、使えない位置での参照（例: リズムトークンを含む定義を `mel:` で使う）。 |
| 同時複数音 | `[...]` の各音にオクターブが必要です。括弧の中に空白は書けず、`]` の後の長さは必須です。 |

### プレビューがおかしい・更新されない
<!-- help-sources: extension:4 -->

- プレビューは描画できる部分だけを表示します。エラーで無視された行は表示されないので、まず「問題」パネルの内容を直してください。
- プレビューはアクティブな GuitarDSL エディタに追従します。別のファイルに切り替えると、プレビューも切り替わります。
- カポバーでカポを変えたり初心者モードを ON にしたりすると、プレビューは変換後の内容を表示します。ファイル自体は **DSLに適用** を押すまで変わりません。編集によって変換できなくなると、元の内容に戻して警告を表示します。

### PDF を保存できない
<!-- help-sources: extension:3 -->

PDF を保存できないときはエラーメッセージを表示し、途中までのファイルは残しません。

- 保存先フォルダーに書き込めるか確認してください。
- ファイルが他のアプリで開かれていないか確認してください。

PDF は常に現在のプレビュー（カポの一時変更や初心者モードを含む）と同じ内容です。

### カポ・初心者モード・移調を適用できない
<!-- help-sources: extension:4B syntax:4 -->

変更できない場合は理由が表示されます。主な理由は次のとおりです。

- DSL にエラーがある
- `capo:` が 0〜12 の整数でない
- `C@label` のようなラベル付きコードを使っている
- 移調後のコード名が `chord` 定義と同じ名前になる
- メロディの音がオクターブ 0〜9 の範囲を超える

使われなくなる可能性のある `chord` 定義は通知されますが、削除はされません。

### YouTube 自動採譜
<!-- help-sources: extension:3 -->

- **API キー**: 初回実行時に Gemini API キーの入力を求められます。変更は **GuitarDSL: Gemini API キーを設定**、削除は **GuitarDSL: Gemini API キーを削除** で行います。
- 受け付ける URL は、`youtube.com`・`www.youtube.com`・`youtu.be` の公開動画の `https://` URL だけです。
- 次の場合はエラーメッセージを表示します。
  - ネットワーク・利用上限・認証の問題
  - 非公開の動画
  - 不正な結果
  - 4/4 以外の曲

  エラーのときはドキュメントを作成せず、既存のファイルも変更しません。

### ローカル音源の採譜（実験的）
<!-- help-sources: extension:3 -->

- 入力できる WAV ファイルの条件は次のとおりです。MP3・AAC・M4A・FLAC には対応しません。
  - 非圧縮の整数 PCM
  - 16 bit または 24 bit
  - モノラルまたはステレオ
  - 44.1 kHz または 48 kHz
  - 128 MiB 以下、15 分以下
- デスクトップ版 VS Code のローカルファイルだけに対応します。vscode.dev やリモート環境では使えません。
- 同時に実行できる解析は 1 つだけです。解析は進捗通知から取り消せます。
- 安定した拍や完全な小節が見つからない場合は、ドキュメントを作成しません。詳細は出力チャンネル **GuitarDSL Audio MIR** を確認してください。
- 結果は実験的な下書きです。コードやストロークは耳で確認してください。

### 再生について
<!-- help-sources: syntax:16 -->

GuitarDSL は楽譜を描画する拡張機能で、演奏（再生）は行いません。テンポ・強弱などのスコアイベントも記譜として表示するだけです。
