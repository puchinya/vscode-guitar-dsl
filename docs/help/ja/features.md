## 機能

### GuitarDSL サイドバー
<!-- help-sources: extension:3 extension:4C -->

アクティビティバーの **GuitarDSL** アイコンを押すと、**はじめに** ビューが開きます。ファイルを開く前から使えます。上部の対象行にはアクティブな GuitarDSL ファイルだけを表示し、別の開いているファイルへ自動で切り替えません。

- **新規作成**: **テンプレートから新規作成**（コード譜（基本）・メロディ付き・リードシート）と **サンプルを開く**（同梱の 5 つ）。どちらも編集できる無題のドキュメントとして開くので、元ファイルは変わりません。
- **開く・取り込む**: `.guitardsl` / `.gdsl` ファイルを開く、Guitar Pro 7/8 を取り込む、YouTube またはローカル WAV から採譜する操作があります。採譜は実験的です。
- **編集支援**: アクティブな楽譜を Preview で開くか、共通 Inspector を開きます。Inspector は対象ファイルがない場合も空状態を表示できます。
- **書き出す**: アクティブな楽譜を PDF または Guitar Pro 7 に書き出します。
- **ヘルプ**: 同梱の GuitarDSL ヘルプを開きます。

Preview と書き出しは、クリックした時点でアクティブなエディタを使います。アクティブなエディタが GuitarDSL 以外なら警告を表示し、他の開いているファイルへ切り替えません。コマンドパレットの **GuitarDSL: テンプレートから新規作成** と **GuitarDSL: サンプルを開く** でも同じ操作ができます。

### GuitarDSL Inspector
<!-- help-sources: extension:3 extension:4B extension:4D extension:4 -->

Inspector は、機能の移行に合わせて文書ごとの編集補助をまとめる表示先です。コマンドパレットから **GuitarDSL: Inspectorを開く** を実行します。対象はアクティブな GuitarDSL 文書だけで、該当文書がない場合は空状態を表示します。入力、カーソル移動、通常の文書切替では自動表示しません。上部の「文書」「変数」「楽譜設定」「コード進行」タブは同じ Inspector 内を切り替えます。コード進行は有効な候補セッションがあるときだけ選べます。未適用の変数 / 設定変更を破棄する確認をキャンセルすると現在の表示と草稿を保ちます。試聴中に別タブへ移る場合、試聴停止の確認が完了してから切り替わります。文書情報は読み取り専用ですが、「変数」タブではlet定義を編集できます。コード進行の試聴は Inspector、通常の再生と練習は Preview が担当します。View を移動した場合、VS Code はその配置を保ちます。

**GuitarDSL: 変数を表示** は、アクティブな文書のlet変数一覧を既存 Inspector に表示します。コード図のchord定義とは分けて扱います。定義の使用状況と参照位置を確認し、参照へジャンプできます。新規作成、複製、名前変更、定義編集、未使用定義の削除は草稿として確認し、**変更を適用** したときに一回の元に戻せる編集として反映します。名前変更は全参照を更新します。使用中の定義は削除できません。参照箇所をPreviewで編集するときは、全参照に効く定義編集か、その箇所だけの安全な展開かを選びます。

### エディタ支援
<!-- help-sources: extension:2 extension:5 extension:5A extension:5B -->

- **シンタックスハイライト**: ヘッダー、セクション、コード、リズム、歌詞、メロディ（`mel:` / `lyr:`）、コード定義、スコアイベント、`let` フラグメントを色分けします。
- **編集補助**: `#` によるコメントの切り替え、括弧・引用符の自動補完。
- **アウトライン**: メタデータ、セクション、各小節行のコード要約、スコアイベントを、アウトラインビューと「ファイル内のシンボルへ移動」に表示します。
- **診断**: 入力中にエラーと警告を表示します（**トラブルシューティング** を参照）。
- **Code Actions**: 選択したコード名・音符の実音移調、異名同音の切り替え、長さの2倍 / 半分、音名の標準化、リズムの `let` 抽出・展開を行えます。未使用コード定義の Quick Fix と、繰り返し候補から一か所を抽出する Hint も表示します。編集できるトークン全体を選択してください。コメントや選択範囲外の書式は保持されます。

### 楽譜プレビュー
<!-- help-sources: extension:3 extension:4 syntax:11 -->

**GuitarDSL: プレビューを横に開く** で、描画した楽譜をエディタの横に表示します。プレビューは編集と、アクティブな GuitarDSL エディタに追従します。高さ 48 px の再生行に再生・一時停止・停止・シーク・現在時間と全時間を表示します。その直下には高さ 44 px の楽譜設定行が常にあり、カポ・色付き弾きやすさ・初心者モードを直接操作できます。幅 840 CSS px 以上ではバレー方針、カポ選択方法、Inspector への導線も表示します。初心者モードの置き換え結果やカポ警告がある場合は、行内の詳細ボタンから確認できます。それより狭い幅では **その他** から同じ情報を確認できます。再生できない場合も、操作を無効にして理由を表示します。

再生行の「通常 | 編集 | 練習」でPreviewの表示を切り替えます。幅600 CSS px未満では選択中モードを示すメニュー、600 px以上では3つのセグメントを表示します。**通常** は楽譜設定行まで、**編集** は選択対象に応じた下端固定ドックまでを表示し、既存InspectorをPreview対象文書の「変数」で開きます。**練習** は練習操作行と固定4小節ガイドを表示します。Practiceのコマンドも同じモードを切り替えます。編集ドックとPractice行・ガイドは同時に表示しません。練習へ戻っても再生は自動開始しません。未適用の編集草稿がある状態で編集を離れるときは確認を出し、キャンセルすると編集モードと草稿を保ちます。

編集モードでは譜面を選択するとコード名・音符・リズム・TAB・歌詞などの編集欄がドックに現れます。コード名を変更し、コード・メロディ音符・リズム・TABのトークンを追加または削除できます。音符グループや小節内音符を編集し、TAB和音内のノートを追加・削除し、歌詞を編集できます。各操作は元のDSLテキストに一回の元に戻す編集として反映され、Previewのスクロール位置と選択を保てる場合は再描画後に復元します。対象位置が曖昧、または安全に変更できない場合は理由を表示してソース編集へ案内します。一時カポや初心者変換が有効な場合は編集に切り替えず、既存のInspector草稿と一時設定も変更しません。

- **練習** では楽譜設定行の下に高さ42 pxの操作行を表示し、下端固定ガイドが演奏位置に追従します。既定の **コンパクト** では、メロディ、歌詞、ベクトル SVG の奏法記号、コード名、正方形のコード図を演奏順に表示します。4小節を常に保持し、幅や譜面密度で画面に収まらない部分は横スクロールで表示できます。コード名と図は小節境界を避け、コード区間の中央に揃います。次のペアへ進むと直前に演奏した側だけが220msでクロスフェードします。演奏中のペアと右端の次コード名はそのまま残ります。シーク、ループ折返し、表示幅変更時はすぐに表示を更新します。**詳細グリッド** は連続タイムライン表示を保ちます。**メロディ** はその行だけ、**コード図** は図だけを表示切替できます。自動4分・8分・16分グリッドは全曲共通で、手動分割はガイド表示だけを変えます。波線 `〜` は記譜音価または有効なタイの継続を表し、空振りではありません。ガイド設定はこのPreviewの一時表示で、DSL、音源、再生位置を変更しません。
- 下端固定の練習ガイドは演奏位置に追従します。既定の **コンパクト** では、メロディ、歌詞、ベクトル SVG の奏法記号、コード名、正方形のコード図を演奏順に表示します。4小節を常に保持し、幅や譜面密度で画面に収まらない部分は横スクロールで表示できます。コード名と図は小節境界を避け、コード区間の中央に揃います。次のペアへ進むと直前に演奏した側だけが220msでクロスフェードします。演奏中のペアと右端の次コード名はそのまま残ります。シーク、ループ折返し、表示幅変更時はすぐに表示を更新します。**詳細グリッド** は連続タイムライン表示を保ちます。**メロディ** はその行だけ、**コード図** は図だけを表示切替できます。自動4分・8分・16分グリッドは全曲共通で、手動分割はガイド表示だけを変えます。波線 `〜` は記譜音価または有効なタイの継続を表し、空振りではありません。ガイド設定はこの Preview の一時表示で、DSL、音源、再生位置を変更しません。
- **再生設定** を開くと **カウントイン** と **メトロノーム** を操作できます。どちらも既定では OFF です。
- **表示・出力** を開くと *1ページ*、*見開き*、*Web*、用紙サイズ（A4・A3・A5・B4・B5・Letter）、向き（*縦* / *横（見開き）*）、**📄 PDF保存** を操作できます。Web はページに分けず続けて表示し、手動の改ページ位置を点線で示します。
- **? ヘルプ** からこのガイドを開きます。各パネルはクリックまたはキーボードで開閉でき、Escape で閉じて起動ボタンへ戻ります。
- 再生音はシンプルな合成音です。カウントインは弱起から始まる楽譜でも、最初の小節と同じ拍子の 1 小節分を再生してから曲を始めます。

### コード進行の提案と試聴
<!-- help-sources: extension:3 extension:4 -->

**GuitarDSL: コード進行を提案** は、アクティブな GuitarDSL エディタの CodeLens から共通 Inspector を開きます。最初は4小節で、安全に置換できる場合は置換、できない場合は安全な本文末追加を表示します。Inspector で4・8・16小節と置換・追加を切り替えられます。実行できない選択肢は無効になります。最大5件の決定論的候補をコード列・スコア・調性の根拠とともに表示し、クリックまたはキーボードで選べます。候補は固定カタログと現在の調、カポ、メロディから計算します。スコアは候補比較用のヒューリスティックです。コードセルの補完候補から、次のコードを選ぶこともできます。

- 候補は、対象範囲のコード名だけを置き換えるか、本文末にコード小節を追加できます。リズム、メロディ、歌詞、コメント、空白は保持されます。空コードセルでは直前の `@key` を調の判定に使います。転調後の小節から始められますが、置換範囲の内側に `@key` イベントがある場合（同じ調の再指定を含む）は適用できません。複数の調をまたぐ範囲や和声が曖昧な範囲も対象外です。リピート小節、複数コード、明示的なコード長、カスタムボイシング、TAB、解析エラーなど、安全に解決できない範囲にも適用できません。
- 候補を選ぶとエディタに提案コードを Decoration で表示し、Preview が既に開いていれば B の表示も更新します。ソース、文書 version、Undo 履歴は変わらず、自動再生もしません。Inspector の **試聴**、**停止**、**A 原文**、**B 候補**、試聴モード、速度、**適用**、**閉じる** を使えます。試聴モードは単一コード、進行全体、メロディ付き進行、全曲から選べます。8・16小節候補は4小節パターンをそれぞれ2回・4回繰り返します。**試聴** は Inspector から直接開始します。再生中の Preview があれば先に停止し、試聴終了後は Preview の通常再生や練習を再開できます。速度は 50%〜150% で、A/B や候補を切り替えても保持されます。候補・A/B・速度の切替時は試聴中の音を停止します。Preview には通常の再生、練習、PDF 操作が残ります。
- **候補を適用** を選び、確認すると、候補が一度の元に戻せる編集として書き込まれます。適用前に文書が変わった場合は、適用を中止します。

### 練習モード
<!-- help-sources: extension:3 extension:4 -->

ツールバーの **練習** を ON にすると、その下に練習用の操作行が表示されます。OFF にすると行と Tab 停止点がなくなります。練習モードが変えるのは再生だけで、GuitarDSL のソースや記譜上のテンポは変更しません。

練習モードでは画面下部に全曲の弾き語りガイドも固定表示します。**詳細タイムライン** はメロディ、歌詞、奏法、コード名、コード図が全小節で一つの時間軸を共有します。左の見出しと次のコード名は固定され、時間軸だけを横スクロールできます。メロディは音高と音価を表すバー、歌詞は音符に対応する音節で表示します。**メロディ** を OFF にするとメロディ行だけを隠し、**コード図** は個別に表示できます。**コンパクト4小節表示** はストローク記号、コード名、コード図を4枚の白い小節カードにまとめ、持続するストロークごとに継続 `〜` を最大1つ表示します。4小節を常に保持し、幅や譜面密度で見切れるカードは横スクロールで表示できます。コード名とコード図は小節内のコード区間中央に揃います。再生が表示中の3小節目に入ると、直前に演奏したペアだけが220msで切り替わります。停止中の **前へ** / **次へ** は2小節ペアをシークせず演奏順に閲覧できます。リピートや編曲も再生順に並び、シークとループ折返しは現在小節に追従します。分割の **自動** は全曲の音価を調べ、必要に応じて全小節を4分・8分・16分の同じグリッドにそろえます。表示モードと手動の分割設定はこの Preview の一時表示設定で、DSL や再生位置を変えません。

- **速度** は 25%〜200% を 5% 刻みで選べます。選んだ速度はプレビューに保存されます。
- 再生ヘッドは譜面上の音符・リズム符の位置に合い、その間はスコア時刻に沿って進みます。
- **ループ** は現在の小節、現在のセクションに属する連続した演奏範囲、または A/B 区間を繰り返します。セクション見出しはその小節から次の見出しの直前までの書かれた小節に適用されます。**セクション** は名前付きセクション内のどの小節からでも選べます。演奏順で連続する反復は同じ範囲になり、別セクションを挟む同名セクションは別範囲です。**A** は現在の再生位置を記録し、以前の B を消します。**B** は A より後に設定してください。**クリア** でループと両方の位置を消します。ループは A を含み、B の直前で止まる区間です。
- **カウントイン** が ON の場合、練習再生を 0 以外の位置から始めると、その演奏位置の小節の拍子とテンポで 1 小節分を鳴らします。カウントインは練習速度に従い、ループのたびには繰り返しません。
- **追従** は再生中の小節が見えるようにプレビューをスクロールします。プレビューを手動でスクロールまたは移動すると追従は OFF になります。ソースエディタの選択範囲やカーソルは移動しません。
- コマンドパレットから **GuitarDSL: プレビュー再生を再生 / 一時停止**、**プレビュー再生を停止**、**練習モードを切り替え**、**練習ループの開始位置 (A) を設定**、**練習ループの終了位置 (B) を設定**、**練習ループを解除**、**練習速度を下げる**、**練習速度を上げる** も実行できます。これらのコマンドには任意のキー割り当てを設定できます。

幅 600 px では再生操作、練習、2 つの設定ボタン、ヘルプを表示します。狭い幅ではラベルがアクセシブル名付きのアイコンに切り替わります。さらに狭い幅では補助操作ボタンを横スクロールできますが、通常の再生操作はツールバーに残ります。

小節は自動で段に折り返します（既定は 1 段 4 小節、`measures_per_row` で変更）。段がページに収まらないときと、`pagebreak` / `---` 行の位置で改ページします。1 ページ目にはコードダイアグラム付きのヘッダー、2 ページ目以降には簡易ヘッダーを描画します。

`tab:` または `tab[1]:` がある段では、縦に積んだ `T` / `A` / `B` クレフ、数字の後ろで途切れる弦線、中央配置のフレット数字、譜表上のリズム記号を備えた標準的な6弦 TAB 譜表を、メロディとその歌詞の下に表示します。TAB 自身にリズムがあるため、暗黙のスラッシュ譜表は省略します。明示的に書いたリズムは `show_rhythm: true` で併記できます。TAB と PDF は同じページ SVG 描画経路を使います。

メロディ、表示中のリズム、TAB のうち2つ以上の譜表がある段では、左に音楽用ブレースを1つ表示し、小節線を譜表間の隙間で接続します。TAB だけのときは表示されない暗黙のリズム譜表を数えません。

### PDF 出力
<!-- help-sources: extension:3 extension:4 -->

**📄 PDF保存**（または **GuitarDSL: PDF出力 / 印刷**）で、プレビューと同じ内容をベクター PDF として保存します。用紙サイズと向きはツールバーでの選択に従います。ブラウザは不要です。フォントを同梱しているので、PC にインストールされたフォントに左右されません。印刷は保存した PDF から行います。

### Guitar Proファイルの読み込みと書き出し
<!-- help-sources: extension:3 -->

コマンドパレットから **GuitarDSL: Guitar Pro 7/8をインポート** すると、対応する `.gp` ファイルから選択したギタートラックを新しい無題の GuitarDSL 文書として開きます。複数の対応トラックがある場合は読み込むトラックを選びます。元のファイルは変更しません。

トラックを選んだ後、**原曲に忠実にインポート**（既定）または **コードストラム用に最適化** を選びます。忠実な読み込みは従来どおりTABや音高を保ちます。最適化は小節全体がコードストラムとして扱える場合に、コード記号と正確な音価のリズムスラッシュへ変換します。同じ和声の反復攻撃では生成コード名を繰り返さず、ソースに明示されたコード名は保持します。TAB拍のない空小節やコードのみの小節も、リズム攻撃を追加せず保持します。休符や拍子などの小節構造も保ちます。

GP7/GP8 `.gp` の読み込みは、選択した6弦ギター1トラック・1譜表・対応する声部が対象です。選択トラック内に対応できない音楽的意味がある場合は読み込みを中止します。その他のトラック、音声、サウンド設定、表示レイアウトは、コマンドが損失ポリシーを提示した場合に限り省略できます。

最適化できない場合や最適化出力のシリアライズ・再検証に失敗した場合は理由を表示し、忠実な読み込みに切り替えるかキャンセルできます。切り替えでは読み込み済みの結果を再利用します。作成前に、TABの音高・ボイシング・運指の省略、推論したコード、表示設定や対応歌詞の変更をまとめて確認します。選択した出力を検証できない場合は文書を作成しません。

セクション名と二重小節線は保持します。Section の表示文字だけが別に指定されている場合は損失として提示します。自由拍子、マスターバーのフェルマータ、譜表表示フラグが異なる複数の score view は、推測せず読み込みエラーにします。

**GuitarDSL: Guitar Pro 7へエクスポート** は、現在の GuitarDSL 文書を GP7 `.gp` 形式で保存します。インポート直後の無題文書も、保存前にそのままエクスポートできます。コマンドパレットまたは Explorer のコンテキストメニューから実行します。エディタ右上にはエクスポートボタンを表示しません。保存前に対応範囲と変換で失われる情報を確認し、既存ファイルは上書きしません。自作した契約fixtureはGP8 8.1.5で開いて表示・再保存・再取込を行い、譜面意味が一致することを確認しました。GP7アプリでの互換性は未検証ですが、GP7形式の自動インポート/エクスポート検証は行っています。

### コードダイアグラムとコードダイアグラムエディタ
<!-- help-sources: extension:4A syntax:7 -->

楽譜で使ったコードは、ヘッダーに指板図として描画されます。押さえ方は、ファイル内の `chord` 定義があればそれを使い、なければ組み込みのライブラリから選びます。`F/A` のようにライブラリに専用の押さえ方がない分数コードは、上のコード（`F`）の押さえ方で描きます（`G/B`、`D/F#` には専用の押さえ方があります）。Standard 以外の調弦では、鳴るコード名が一致するプリセット形だけを表示します。カポ位置からの相対フレットで描き、カポの弾きやすさや初心者モードの評価にも同じ調弦と押さえ方を使います。コードエディタの音名判定も曲の調弦に従います。`C@barre` のようにラベルを付けると、同じコードの複数の押さえ方を使い分けられます。

**GuitarDSL: コードダイアグラムを編集** で GUI エディタを開きます。開き方は次の 3 つです。

- `chord` 行の上の CodeLens「ダイアグラムを編集」
- プレビューのダイアグラムのクリック
- コマンドパレット

エディタでは、プリセットの選択、フレットのクリック、開放弦・ミュート、指番号、セーハ、開始フレットを編集できます。鳴っている音からコード名の候補も表示します。保存すると `chord` 行を挿入または置換します（元に戻せます）。

### カポと弾きやすさ
<!-- help-sources: extension:4 -->

Preview のネイティブカポ一覧を開くと、各位置のスコアと日本語の段階を比較できます。推奨位置だけに ★ が付きます。候補も番号から表示し、隣の「カポ」ラベルと重ねません。一覧を閉じている間、選択欄には番号だけを表示します。変更できない候補も無効状態で一覧に残り、スコアまたは段階がない場合は開いた一覧で「評価できません」と表示します。

Preview の常設 **楽譜設定** 行からカポを選び、弾きやすさのスコアと段階を確認し、初心者モードを直接切り替えられます。弾きやすさは数値・文字・色で示し、とても簡単／簡単は緑、普通は黄土色、難しい／とても難しいは赤、未評価は中立色です。未評価を 0 点として表示しません。幅 840 CSS px 以上ではバレー方針、自動／固定カポ、Inspector の詳細リンクも行内に表示し、それより狭い幅では **その他** を開きます。全候補の比較と詳細確認には **GuitarDSL: 楽譜設定を編集** または **GuitarDSL: カポ / 弾きやすさを編集** で共通 Inspector を開きます。現在の調弦でコード名は鳴る響きが変わらないように書き換えて表示します。`tuning`、`key`、メロディは変更しません。

- 各カポ位置に弾きやすさ（0〜100、「とても簡単」〜「とても難しい」）を表示し、最も弾きやすい位置に *★ 推奨* を付けます。
- Inspector の **DSLに適用** で、1 回の元に戻せる編集としてファイルに書き込みます。弾きやすさを評価できない楽譜は「評価できません」と表示し、0 点として扱いません。

TAB を含む文書では、ソースを書き換えるカポ変更は TAB 対応の変換機能ができるまで未対応として報告されます。

### 初心者モード
<!-- help-sources: extension:4 -->

Preview の **楽譜設定** 行から初心者モードを ON にすると、セーハを使わない自動カポが始まります。幅 840 CSS px 以上ではバレー方針と自動／固定カポを行内で切り替えられ、それより狭い幅では **その他** を開きます。カポ／弾きやすさの詳細リンクは Inspector のカポのセクション、初心者モードの詳細リンクは **初心者モード** のセクションを開きます。詳細な候補と置き換え（例: `F → Fmaj7`、`G7 → G`）を比較できます。キーとメロディの鳴る音は変わりません。

- **バレーコード** は *許可する* / *使用しない* を選べます。*使用しない* ではセーハが必要な押さえ方を使いません。
- Preview と PDF は同じ一時設定中の有効スコアを使います。Preview の設定は DSL を変更しません。Inspector の **DSLに適用** で 1 回の元に戻せる編集として反映します。初心者モードを OFF にすると元の楽譜に戻ります。

TAB を含む文書の初心者モード変換は、明示された弦・フレットを保つ仕様が定義されるまで未対応として報告されます。

### 楽譜設定
<!-- help-sources: extension:3 extension:4B -->

**GuitarDSL: 楽譜設定を編集** で、共通 Inspector に曲全体の設定を表示します。セクションは次の 3 つです。

- **カポ / 弾きやすさ**: すべてのカポ位置とスコア、推奨、コードの対応。
- **初心者モード**: 上記の設定と置き換え。
- **移調**: 曲全体を −11〜+11 半音、または目的のキーへ移調します。鳴る調・メロディ・コードが変わります。カポは「そのまま」「推奨」「指定」から選べます。

Preview の **一時楽譜設定** と Inspector の候補選択は、Preview が同じ文書を表示している場合にその結果を反映します。Preview を自動で開いたり、DSL を編集したりしません。Inspector の草稿中に Preview から設定を変えると、Preview の選択が優先されます。Inspector を開いたままユーザーが Preview を開くと、その時点の設定草稿が Preview に反映されます。閉じると、その Preview を開く直前の状態に戻ります。移調は **DSLに適用** するまで Preview を変えません。適用前に確認が表示され、確定すると 1 回の元に戻せる編集になります。**GuitarDSL: カポ / 弾きやすさを編集** は同じ Inspector をカポのセクションで開きます。TAB を含む文書では、ソースを書き換えるカポ・移調操作を未対応として報告し、文書を途中まで書き換えません。

### 伴奏パターンの変更
<!-- help-sources: extension:3 -->

**GuitarDSL: 伴奏パターンを変更（ストローク／アルペジオ）** は、小節のリズムを、58 種類のストローク・アルペジオのパターンから選んだものに置き換えます。開き方は次のとおりです。

- セクション見出しの上の CodeLens「伴奏パターンを変更 [セクション名]」
- コマンドパレット（最初に、楽譜全体か 1 つのセクションかを選びます）

選び方は 2 段階です。まず、対象の拍子に合うカテゴリ（4/4 は 8ビート・16ビート・シャッフル・アルペジオなど、ほかの拍子は 3/4 ワルツ・6/8・12/8 など）を選びます。次に、Pop / J-POP・Rock / Punk / Metal・Funk などの用途ごとに区切られたパターンを選びます。今のパターンがカタログのものと同じときは、先頭に「現在のパターンに近い候補」が出ます。

- 変わるのはリズムだけです。コード・歌詞・メロディ・コメント・`%` は変わりません。弱起の小節も変わりません。
- 拍子が混ざった楽譜では、楽譜全体への適用はできません。セクションごとに選んでください。
- `%` の意味が変わる場合や、インラインの音符がある小節は変更しません。
- 変更は 1 回の元に戻せる編集です。

### YouTube 自動採譜（Gemini・実験的）
<!-- help-sources: extension:3 -->

**GuitarDSL: YouTubeから採譜（実験的）** は、公開されている YouTube の URL を Google Gemini に送り、コード・リズム・メロディを書き起こした結果を YouTube パネル内の読み取り専用プレビューに表示します。**コピー** で通常の GuitarDSL エディターに貼り付けて編集できます。成功時に未保存ドキュメントは自動作成されず、パネルを閉じるとプレビューは破棄されます。パネルではキー管理と詳細設定を別々に開閉できます。キー状態には通常、保存済みか未設定かを表示します。シークレットストレージから状態を読み取れない場合は「キー状態を確認できません」と表示し、保存済み / 未設定と断定しません。その場合は **設定・変更** からキーを入力して保存してください。キー自体は状態表示に出しません。**採譜設定（詳細）** には BPM、カポ、ビート、伴奏ファミリーとプリセット、繰り返し圧縮、モデルがあります。URL と保存済みまたは入力済みのキーがある場合に採譜を開始できます。開始時に保存済みキーを読み取れない場合はエラーを表示し、Gemini 呼び出しや結果プレビューの生成は行いません。キーを保存し直して再試行してください。処理中にパネルを閉じても処理は続きますが、その結果は破棄されます。処理が終わる前にパネルを開き直した場合、Hostから現在の処理状態を受け取り、完了後に開始を再試行できます。

- 対応するのは 4/4 拍子の曲だけです。
- 伴奏パターンは「自動」のほか、4/4 のパターン（Swing などのフィールが必要なものを除く）をカテゴリ → パターンの順に選んで指定できます。
- Gemini API キーが必要です。キーは VS Code のシークレットストレージに保存されます。設定は **GuitarDSL: Gemini API キーを設定**、削除は **GuitarDSL: Gemini API キーを削除** で行います。
- 使用するモデルは設定 `guitardsl.gemini.model` で指定します。
- ネットワークを使用します。既存のファイルは上書きしません。
- 開く前に構造検証を通しますが、それによって音楽的な正しさが保証されるわけではありません。コード、リズム、メロディ、歌詞、BPM、小節境界などの推定が誤ることがあります。結果を下書きとして扱い、使用前に必ず確認・修正してください。

### ローカル音源の採譜（実験的）
<!-- help-sources: extension:3 -->

**GuitarDSL: ローカル音源から採譜（実験的）** は、PC 上の WAV ファイルをネットワークも API キーも使わずに解析します。キー・BPM・コード・ストローク位置を推定し、未保存の新しいドキュメントとして開きます。

- ダウン／アップは拍の中の位置から推定します。
- 4/4 拍子だけに対応します。
- 結果は下書きとして扱ってください。
- 解析の詳細は出力チャンネル **GuitarDSL Audio MIR** に記録されます。

この機能は **実験的** で、デスクトップ版 VS Code とローカルファイルだけに対応します。

### AI 連携（VS Code の Agent / Chat）
<!-- help-sources: extension:1 extension:8 -->

VS Code 1.109 以降では、VS Code 標準の Agent / Chat から GuitarDSL を扱えます。任意の機能です。AI を使わなくても、他の機能はすべてそのまま動きます。拡張機能自身は AI モデルを呼び出しません。使うモデルやチャットは VS Code 側の設定に従います。

- **言語の知識**: Skill `guitardsl-language` が、GuitarDSL の言語仕様から必要な部分だけを Agent に読ませます。`.guitardsl` / `.gdsl` ファイルの編集時には、仕様にない書き方をしない・編集後に検証する、という指示が自動で適用されます。GuitarDSL ファイルがまだない状態で新しい曲を頼んだときにも、この指示が適用されます。
- **新しい曲の作成**: 「新しい曲を作る」依頼では、Agent は既存の GuitarDSL ファイルを編集対象として再利用しません。新しい GuitarDSL 文書を作ってから、その文書だけを検証・伴奏分析・伴奏適用します。新曲作成時の GuitarDSL の書式は、拡張機能に同梱された言語仕様と伴奏ガイドを参照します。既存スコアやサンプルから記法を推測せず、同梱仕様を使います。既存の GuitarDSL 文書やサンプルを読むのは、ユーザーが特定のファイルを参考資料またはテンプレートとして明示した場合だけです。伴奏まで含めた新しい曲を Agent に頼むと、Agent はまずストロークを書かずに曲の構造（セクション、コード、メロディ、歌詞）を書きます。その下書きを検証してから `#guitardslAccompaniment` で分析し、`#guitardslApplyAccompaniment` で全セクションの伴奏を一度に付け、最後にもう一度検証します。通常の新曲作成では、Agent は各セクションの大まかな強弱や奏法だけを決め、具体的な正規伴奏パターンは拡張機能が決定します。ダウン / アップを Agent が自分で書くことはありません。伴奏ツールを実行できなかったときは下書きをそのまま残し、伴奏が未完成であることを伝えます。リズム記法を手で書くことは、これまでどおりできます。
- **ツール**: プロンプトに `#` で参照して使えます。
  - `#guitardslValidate`: 楽譜のエラーを確認します。ファイルは変更しません。
  - `#guitardslPlayability`: カポごとの弾きやすさを分析します。ファイルは変更しません。
  - `#guitardslApplyCapo`: カポを変更します。
  - `#guitardslApplyBeginner`: 初心者モードを適用します。
  - `#guitardslTranspose`: 実音を移調します。
  - `#guitardslAccompaniment`: セクション・拍子・今の伴奏と、使えるパターンを分析します。ファイルは変更しません。
  - `#guitardslApplyAccompaniment`: セクションごとに伴奏を付けます。「Aメロは控えめ、サビは強めの 8 ビート」「サビを少し食い気味に」のような依頼に使えます。曲調はモデルが判断し、ダウン / アップ・拍数・コードの切り替わりでの弾き方は拡張機能が正しく決めます。セクションの切り替わりや曲の終わり方も、歌の終わりに合わせて調整できます。
- **ファイルを変更するツール**は、実行前に対象のファイルと操作内容を確認します。計算はプレビューの **DSLに適用** と同じで、1 回の元に戻せる編集として書き込みます。適用できない場合はファイルを変更しません。同じファイルに対する変更は 1 つずつ実行されます。
- ファイルを変更するツールは、Agent が指定したファイル（パスまたは URI）だけを変更します。確認ダイアログに表示されたファイル以外が変更されることはなく、確認のあとで別のファイルに切り替えても対象は変わりません。保存していない無題のファイルも対象にできます。
- 検証・分析のツールは、ファイルを指定しない場合、コマンドと同じ順で対象を決めます（アクティブなエディタ → 表示中のエディタ → 最後に使った・開いている GuitarDSL ファイル）。

### スコアイベントと高度な記譜
<!-- help-sources: syntax:12 syntax:16 -->

曲の途中で調・テンポ・拍子・フィール・オッターヴァを変えたり、強弱・リハーサルマーク・テキストを付けたりできます。ハンマリング、スライド、チョーキング、装飾音符、スラー、パームミュート、レットリングなどの奏法も描画します。これらは**記譜のみ**です。楽譜に描画するだけで、音は鳴らしません。
