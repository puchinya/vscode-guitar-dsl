Open-source guitar score editor

Create guitar scores
from text.

GuitarDSL is open-source software (OSS). Write the kind of chord, strumming and lyric charts often found in published singer-songwriter books, singer-songwriter scores with a vocal melody, or solo guitar tablature. Edit a compact domain-specific language (DSL) and see the score preview alongside your text.

Scores for different uses

Three score examples

Using the original song “Sora-iro no Shirushi” (“A Sign in the Blue Sky”), these examples show a singer-songwriter chart without a vocal melody, one with a vocal melody, and a solo guitar TAB score. Each DSL example is paired with the same content rendered in the Web app. The song, lyrics and melodies were written for this demonstration and are unrelated to existing works.

Example 01 / Chords, strumming and lyrics

Singer-songwriter chart (without melody)

Write a chart that brings chord names, strumming patterns and lyrics together. It is useful when you want to follow the guitar accompaniment and lyrics without showing sung notes.

Sora-iro no Shirushi.guitardslGuitarDSL
title: 空色の合図
artist: GuitarDSL Original Demo
key: C
bpm: 104
time: 4/4
measures_per_row: 4

[Verse]
| C G   | 4.d 8.d 8.u 4.d 8.d 8.u l:"あさのそらに" |
| Am Em | % l:"ひかりがさす" |
| F C   | 4.d 8.d 8.u 4.d 8.d 8.u l:"まだみぬみち" |
| Dm G7 | % l:"かぜをこえて" |
  • Write chords and rhythm in separate cells
  • Reuse the previous bar’s strumming with %
  • Add bar-level lyrics with l:
Example 02 / Melody, lyrics and accompaniment

Singer-songwriter chart (with melody)

In addition to chords and strumming, write the sung notes and lyrics. Read pitch and duration on the staff while keeping guitar accompaniment in the same score.

Sora-iro no Shirushi.guitardslGuitarDSL
title: 空色の合図
artist: GuitarDSL Original Demo
key: C
bpm: 104
time: 4/4
measures_per_row: 4

[Verse]
| C G   | 4.d 8.d 8.u 4.d 8.d 8.u |
| Am Em | % |
| F C   | 4.d 8.d 8.u 4.d 8.d 8.u |
| Dm G7 | % |

mel: | e4/8 g g/4 d/8 b3 g/4 | a4/8 c5 e/4 b4/8 g e/4 |
lyr: | あ さ の そ ら に | ひ か り が さ す |
mel: | f4/8 a c5/4 g4/8 e c/4 | d4/8 f a/4 b/8 d5 g/4 |
lyr: | ま だ み ぬ み ち | か ぜ を こ え て |
  • Write the vocal melody with mel:
  • Align one lyric syllable to each note with lyr:
  • Keep the same chord progression as the melody-free version
Example 03 / Solo guitar and TAB

Solo fingerstyle guitar TAB

This fingerstyle example combines low accompaniment and an upper melody on one guitar. Specify strings, frets and note values, including simultaneous strings such as [5f3,2f1].

Sora-iro no Shirushi.guitardslGuitarDSL
title: 空色の合図
artist: GuitarDSL Original Demo
key: C
bpm: 104
time: 4/4
measures_per_row: 4

[Verse]
| C G   |
| Am Em |
| F C   |
| Dm G7 |

tab: | [5f3,2f1]/8 3f0 1f0 2f1 [6f3,2f0] 3f0 1f3 2f0 |
tab: | [5f0,2f1]/8 3f2 1f0 2f1 [6f0,2f0] 3f0 1f0 2f0 |
tab: | [6f1,2f1]/8 3f2 1f1 2f1 [5f3,2f1] 3f0 1f0 2f1 |
tab: | [4f0,2f3]/8 3f2 1f1 2f3 [6f3,2f0] 3f0 1f1 2f0 |
  • Alternate low notes and upper-register melody
  • Play bass and melody strings together with [5f3,2f1]
  • Note values carry forward when omitted
Editing, preview and saving

Check your score as you write

Edit the DSL while previewing the score, then export a PDF when needed. Scores and drafts can be saved in your browser. Google Drive is optional and can be used to manage files from Explorer.

Use GuitarDSL

Open the Web editor in your browser and start writing a score. The app’s Help menu explains how to use it.
